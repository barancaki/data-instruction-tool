## HyperScrape Engine v2 - System Documentation

### GENEL BAKIŞ (OVERVIEW)
HyperScrape Engine v2, fuar sitelerinden veri kazımak için geliştirilmiş yüksek performanslı, modüler ve ölçeklenebilir bir sistemdir. 30+ önceden yapılandırılmış site desteği ve 12 farklı template türü ile çalışır.

### MİMARİ (ARCHITECTURE)
```
HyperScrape/
├── config/              # Site tanımları ve ayarlar
│   ├── fair_definitions.py  # Tüm fuar site tanımları
│   ├── loader.py           # Config yükleyici
│   └── settings.py         # Global ayarlar
├── core/                # Ana motor
│   ├── engine.py           # HyperScrapeEngine
│   ├── driver_pool.py      # WebDriver havuzu
│   └── cache.py            # Önbellek sistemi
├── templates/           # Scraping şablonları
│   ├── base.py             # Temel şablon sınıfı
│   ├── tuyap_list.py       # Tuyap liste şablonu
│   ├── link_detail.py      # Link+detay şablonu
│   ├── deutsche_platform.py # Deutsche Messe
│   └── ... (9 template daha)
├── enrichment/          # Veri zenginleştirme
│   ├── email_finder.py     # Email bulma
│   ├── address_finder.py   # Adres bulma
│   └── social_finder.py    # Sosyal medya
├── models/              # Veri modelleri
│   └── fair.py             # Company, FairConfig, ScrapeResult
└── utils/               # Yardımcı araçlar
```

### YENİ SİTE EKLEME (ADDING NEW SITES)

#### ADIM 1: Template Seçimi
Sitenin yapısını analiz ederek uygun template'i seçin:

1. **tuyap_list** - `.filter-list__item` yapısı, detay butonlu liste
2. **link_detail** - Brand kartları → detay sayfası
3. **deutsche_platform** - Deutsche Messe platform siteleri
4. **modal_popup** - Modal popup ile detay gösteren siteler
5. **card_list** - Kart tabanlı düzen
6. **member_cards** - Üyelik dizini siteleri
7. **search_results** - Arama sonucu benzeri düzen
8. **scroll_load** - Sonsuz scroll veya load more
9. **xpath_detail** - Kompleks XPath gerektiren siteler
10. **text_list** - Basit metin listeleri
11. **image_gallery** - Resim galerisi tabanlı
12. **blog_cards** - Blog kartı benzeri düzen

#### ADIM 2: fair_definitions.py'ye Ekleme

`HyperScrape/config/fair_definitions.py` dosyasını açın ve FAIR_DEFINITIONS dictionary'sine yeni tanım ekleyin:

```python
"site_key": {
    "name": "Site Display Name",
    "base_url": "https://example.com/exhibitors",
    "template": "tuyap_list",  # Seçilen template
    
    # Pagination ayarları
    "pagination_type": "page",  # 'page', 'offset', 'scroll', 'load_more', 'none'
    "pagination_param": "page",
    "pagination_url": "https://example.com/exhibitors?page={page}",
    "max_page_auto_detect": True,
    
    # CSS/XPath seçiciler
    "selectors": {
        "company_list": ".exhibitor-item",
        "company_name": ".name",
        "address": ".address",
        "phone": "a[href^='tel:']",
        "website": "a[href^='http']",
        "email": "a[href^='mailto:']",
        "products": ".categories",
        # ... template'e göre gerekli seçiciler
    },
    
    # Template-specific config
    "template_config": {
        "needs_detail_page": False,  # Detay sayfasına gitme gerekli mi?
        "base_url_for_join": "https://example.com"  # Relative URL'ler için
    },
    
    # Enrichment ayarları
    "enable_email_enrichment": True,    # Email bulma aktif mi?
    "enable_address_enrichment": False,  # Adres bulma aktif mi?
    "enable_social_enrichment": False   # Sosyal medya bulma aktif mi?
}
```

### PAGİNATION TİPLERİ

1. **'page'** - URL parametresi ile sayfalama  
   `?page=1`, `?page=2` ...

2. **'offset'** - JavaScript offset ile  
   JavaScript fonksiyon çağrısı gerektirir

3. **'scroll'** - Sonsuz scroll  
   Sayfa sonuna kadar scroll yapılır

4. **'load_more'** - "Load More" butonu  
   Buton bulunup tıklanır

5. **'none'** - Sayfalama yok  
   Tek sayfa, tüm veri orada

### PERFORMANS OPTİMİZASYONU

#### Driver Pooling
```python
# Driver'lar tekrar kullanılır, her seferinde yeni browser açılmaz
driver_pool = DriverPool(pool_size=3)
```

#### Caching
```python
# Son scrape'lerden 1 gün boyunca önbellek kullanılır
cache = ScrapeCache(expiry_days=1)
```

#### Parallel Processing
```python
# 3 parallel worker ile 3-5x hız artışı
parallel = True  # Streamlit arayüzünde seçilebilir
```

### HATA YÖNETİMİ

Tüm template'ler otomatik retry mekanizması içerir:
- Sayfa yüklenme hatası → 3 retry
- Element bulunamadı → Boş string döndür
- Email bulunamadı → Enrichment devreye girer

### GELİŞTİRME REHBERİ

#### Yeni Template Ekleme

1. `HyperScrape/templates/` altında yeni dosya oluştur
2. BaseTemplate'den türet
3. `scrape_page()` metodunu implement et
4. `HyperScrape/core/engine.py` içindeki TEMPLATES dictionary'sine ekle

```python
class MyCustomTemplate(BaseTemplate):
    def scrape_page(self, url: str) -> List[Company]:
        driver = self.driver_pool.get_driver()
        companies = []
        
        try:
            self._load_page(driver, url)
            # ... scraping logic ...
        finally:
            self.driver_pool.return_driver(driver)
        
        return companies
```

### SORUN GİDERME

1. **Site yüklenmiyor**: `Settings.PAGE_LOAD_TIMEOUT` artır
2. **Element bulunamıyor**: CSS selector'ları kontrol et
3. **Email bulunmuyor**: `enable_email_enrichment = True` olduğundan emin ol
4. **Çok yavaş**: `parallel = True` ve `MAX_WORKERS` artır
5. **Cache temizleme**: `.hyperscrape_cache` klasörünü sil
